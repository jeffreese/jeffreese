## What I'm Building

**[Human Markdown](https://github.com/purecontext/human-markdown)** — A WYSIWYG markdown editor for VSCode and Cursor. Read rendered, edit inline, toggle to raw with one keystroke. Open source, MIT licensed. Available on the [VSCode Marketplace](https://marketplace.visualstudio.com/items?itemName=purecontext.human-markdown) and [Cursor Marketplace](https://open-vsx.org/extension/purecontext/human-markdown).

**[Waykeep](https://waykeep.app)** — An offline-first trip planner for individuals and groups, available on both mobile platforms and the web. Currently in development.

**[Forge](https://purecontext.dev/showcases/forge)** _(private)_ — An AI meta-generator that plans applications through the full SDLC and exports AI-enabled development environments. It's how I build everything else.

**[Cairn](https://purecontext.dev/showcases/cairn)** _(private)_ — A persistent AI collaboration system with memory, identity, and multi-instance coordination. The infrastructure behind a longitudinal study in human-AI collaboration.
